# Lab Control 项目简介
- Lab Control 是面向科研课题组的内部管理平台，提供统一登录、成员与权限管理、实验记录和科研资源管理，并配套数据备份。
# 许可证说明
- Lab Control 目前处于内部测试阶段，本仓库用于项目介绍与功能展示。Lab Control 的独立自研模块为闭源。集成的 eLabFTW 采用 AGPL-3.0，Keycloak 采用 Apache-2.0，其他第三方组件遵循各自的许可证。
# 测试环境
- Ubuntu Server 24.04
- Docker 29.9.3
- 内存最低要求 ≥ 2GB
- ZFS(RAIDZ1)
- 硬盘: 系统盘 1块(容量≥48 GB)
        数据盘 ≥ 3块
